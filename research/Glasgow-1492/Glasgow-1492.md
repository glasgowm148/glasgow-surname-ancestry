# WikiTree update notes: [Samuel Glasgow (Glasgow-1492), born about 1726, Moneymore-labelled](https://www.wikitree.com/wiki/Glasgow-1492)

## Suggested replacement research note

The original 1766 Derryloran religious return lists `Sam: Glasco` at
**Gorteen**.<ref>National Archives of Ireland, Parliamentary Return 665, 1766
religious census for Derryloran, `IHP/1/665`, [https://virtualtreasury.ie/item/NAI-IHP-1-665
original return and transcription], accessed 17 July 2026.</ref> The return
does not give his age or parents, so this is a possible occurrence of the
profile rather than a proved identity.

The Samuel Glasgoe at Whitehill appears in the separate 1766 return for
**Kildress parish**, alongside James Glasgow at Corvanaghan.<ref>National Archives of
Ireland, Parliamentary Return 667, 1766 religious census for Kildress,
`IHP/1/667`, [https://virtualtreasury.ie/item/NAI-IHP-1-667 original return],
accessed 17 July 2026; [https://by2022-prod.adaptcentre.ie/loris/RCBL_23_176.JPG/full/full/0/default.jpg
RCB Library `MS 23` transcript, p. 176].</ref>
It should not be presented as a second known residence of the Gorteen man.

## Relationship treatment

Neither return names a father. Keep the current parent attachment uncertain
unless a will, church record, lease or other relational source is found.
