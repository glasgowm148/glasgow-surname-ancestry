## Current conclusion

Glasgow householders, both at Drumearn. It does not identify which, if either,
is this profile or state that

## WikiTree update instructions


### Suggested additions

The original 1766 Derryloran religious return lists two James Glasgow
householders, both recorded as `Jas. Glasgo` at Drumearn. It also lists John
Glasgo at Drumearn, Samuel Glasgo at Gortein and William Glasgo at
Killycurry.<ref>National Archives of Ireland, Parliamentary
Return 665, 1766 religious census for Derryloran, `IHP/1/665`, [https://virtualtreasury.ie/item/NAI-IHP-1-665
original return and transcription], accessed 17 July 2026; independently
transcribed in RCB Library `MS 23`, pp. 162-163.</ref>

The return proves a substantial local Glasgow cluster, but gives no ages or
relationships and does not identify which James, if any, is this profile.
