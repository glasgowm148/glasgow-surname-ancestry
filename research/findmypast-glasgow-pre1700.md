# INCOMPLETE — Findmypast surname-only Glasgow search, pre-1700 audit

Partially collected from the signed-in Findmypast interface on 3 September
2026 using the surname field **Glasgow** only. No place restriction was used.
This is not a complete scrape: pagination was not reconciled, and the saved
date windows leave everything before 1479 and the years 1600–1618 uncovered.

On 3 September 2026 the user manually confirmed that a surname-only search for
`Glasgow` with event year `1600 ±40` displayed **1,684 results**. That displayed
total has not yet been page-enumerated or exported, but by itself proves that
the 33 saved record IDs below are only a small sample.

The [partial export](findmypast-glasgow-surname-pre1700.csv) contains the 27
previously audited pre-1600 rows plus six raw rows from the `1659 ±40` window
(covering the target period 1619–1699). The broad Findmypast date control also
returns later records and generic/unnamed PDF rows; those were not converted
into people.
