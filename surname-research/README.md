# Glasgow surname research

This directory holds evidence and working conclusions that concern the Glasgow
surname as a whole rather than one WikiTree profile.

Use [the surname reconstruction index](INDEX.md) as the main entry point. It
links the generated profile indexes, manual relationship hypotheses, cluster
dashboard, early evidence, and new-person drafts.

## Project scope

The project covers every Glasgow on WikiTree. Evidence concerning any Glasgow
before 1700 is critical and must be recorded here even when it was discovered
while researching an unrelated profile.

- `../data/reference/glasgow-one-tree.xlsx` is the current WikiTree surname snapshot and search
  index. It contains 3,333 profile rows in its present version.
- `indexes/early-profiles.md` is the generated 1475-1700 navigation index.
- `indexes/researched-profiles.md` links active case files and captured relatives.
- `indexes/relationship-hypotheses.md` preserves proposed connections and
  competing topologies without treating them as facts.
- `clusters/README.md` is the continuously maintained quick dashboard, grouping
  significant findings by location/family research cluster and showing whether
  important material is ready to transfer to WikiTree.
- `pre-1700/evidence-register.md` is the central register for early evidence,
  candidate matches, exclusions, and unresolved same-name problems.
- `pre-1700/sources/` contains complete downloaded publications or records.
- `pre-1700/page-extracts/` contains derived page images for rapid verification;
  the complete publication remains the authoritative saved artifact.
- `new-people/` contains only unresolved Glasgow-surname profile drafts, named
  `year_country_preciselocation_name.md`. Once an ID is created or matched, the
  draft moves to `research/<WikiTree-ID>/`.

The workbook and WikiTree profiles are discovery tools, not proof. After finding
a candidate in the workbook, refresh the live profile and assess the cited record.
