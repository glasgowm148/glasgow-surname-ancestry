# Glasgow location and family-cluster dashboard

Last updated: **19 July 2026**

This is the quick index of significant research findings, led by the **new
concrete information still waiting to be added to WikiTree**. People are grouped
by their best-supported location or research family-group. Placement in the same
table is not proof of kinship, but plausible links are included when the combined
place, period and family evidence makes them useful working relationships.

Detailed qualifications belong in the linked findings and transfer files. The
dashboard sentence should say the positive discovery first, then only the
qualification needed to use it correctly.

Use the live-checked [complete WikiTree update queue](../to-update.md) for the
next profile edits.

The evidence-graded [Early Ireland root-cluster map](early-ireland-root-clusters.md)
is the starting point for every pre-1800 Irish placement. It separates dated
Irish occurrences from reconstructed Cross/Derry, Melanchthon and Moneymore
lineages so that a locality clue is not mistaken for a proved pedigree.

The [Early Scotland Glasgow-1098 descendant map](early-scotland-glasgow-1098-map.md)
uses the project's common-root hypothesis to cluster the Scottish branches by
generation and identify the exact gaps. It currently places Rev. John M.A. in the
Corsankell-Stevenston-Kilwinning branch and treats John-3375 as a duplicate test.
